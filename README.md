This game control are such as:
W - Forward
S - Backward
A - Rotate
D - Rotate
Space - Fire
Q - Ascend
E - Descend
Feature:
Drone : Basic Control
Free Aim Camera : For precision and Control
Enemy : Use NavMesh and have basic movement animation and firing animation
Dummy : Environmental things that can be destroyed
Known Bugs:
Particle Effect sometime look like not working hard to reproduce
